# 自动更新错题本规则

当你发现用户（Anno）在编写 C 语言代码时犯了具有代表性的错误（例如：数组越界、作用域错误、嵌套循环逻辑错误、未初始化变量等），或者经历了一次重大的“顿悟（Aha moment）”时，你**必须**主动将这个错误和解析记录到用户的专属错题本中。

**目标文件**：`/Users/anno/C语言learning/bug_diary_find_max.md`

**记录格式**：
请使用追加的方式（Append），在文件末尾添加以下格式的 Markdown 内容：

```markdown
## 🐛 Bug 日记：[给这个 Bug 起个生动的名字]
**日期**：[当天的日期]
**课题**：[涉及的知识点或文件名]
**症状**：[预期输出是什么，实际输出了什么，或者发生了什么崩溃]

### ❌ 案发代码 (Bug 版)
[贴出出错的代码片段，并在旁边用 `// 🚨 错误：...` 的形式标注出 bug 的具体位置]

### 🧠 破案心法 (Lessons Learned)
1. [知识点总结 1]
2. [知识点总结 2]
```

**执行时机**：
在帮用户找出 bug 并讲解完毕后，主动更新该文件，并在回复中告知用户“已将该 Bug 收入错题本”。
